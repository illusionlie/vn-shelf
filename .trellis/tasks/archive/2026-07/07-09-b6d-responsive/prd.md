# B6d 卡片条目缩小 + 三档响应式细化

> 父任务 `07-09-b6-finish`。纯 CSS，建立在 B5c 断点体系上。轻量任务（PRD-only）。

## Goal

缩小 VN 卡片条目尺寸，并把响应式明确为三段心智模型：大显示器 → 中等（办公显示器/平板）→ 手机。用户反馈 768px 断点仍偏大、卡片偏大。

## 确认事实（2026-07-10 代码勘察）

- **断点契约**（`.trellis/spec/frontend/quality-guidelines.md`）：仅 `480 / 768 / 1024`；responsive 规则跟随组件所在文件；禁止 700px 残留。
- **作用范围**：`.cards-grid` 仅 `index.html` 使用；Tier 页为 `tier-vn-card` 缩略图（80×110，768 档 70×98，480 档 60×84），与主页卡片不同量级。
- **容器**：`.container` max-width 1500px（≥1024 档 1600px），`padding: 0 5%`（全局 border-box，5% 相对视口）。
- **现状栅格**（`cards-detail.css`）：
  - base（实际生效于 769–1023）：`minmax(280px,1fr)` gap 30，图高 400px，内容 padding 20px
  - ≥1024：`minmax(300px,1fr)`（gap/图高继承 base）
  - ≤768：`minmax(160px,1fr)` gap 14，图高 280px
  - ≤480：`minmax(140px,1fr)` gap 12，图高 220px，padding 14px
- **问题量化（实测列数）**：1920→4×329 / 1366→3×390 / **1024→2×416** / 900→2×390 / 768→4×162。
  - ≥1024 档的"宽屏优化"（minmax 300）在 1024–1100 小笔记本上反而退化为 2 列巨卡——中档缺失的直接证据。
  - 768/769 密度断崖：4×162 → 2×345（约 2.1× 卡宽跳变），即"768 仍偏大"体感来源。
- **图片高度为各档固定值**，裁切宽高比随实际列宽漂移（base ≈0.70、≤768 ≈0.57、≤480 ≈0.64）；`vn-card-image` 用 `object-fit: cover`。
- **无耦合项**：详情弹窗 `.modal` max-width 700px、`detail-image` 280px 固定，与栅格无关；NSFW overlay / all-age-badge 为绝对尺寸，不随卡片缩放。
- B5c design.md 取舍背景：480/1024 档当时仅"保守增补"，未做密度设计（本任务即补此课）。

## 决策记录（2026-07-10 用户逐项确认）

| # | 决策 | 结论 |
|---|---|---|
| Q1 | 大档密度 | **minmax 210px / gap 24**；中档联动 **minmax 180px / gap 20**。用户备注：上线后观感不满意可再调数值 |
| Q2 | 图片尺寸策略 | **统一 `aspect-ratio: 7/10`**（等于现桌面 280:400 裁切比），删除各档固定高度规则；移动端裁切比从 0.57 收敛到 0.70，已知悉 |
| Q3 | Tier 页卡片 | **不动**（已是缩略图量级） |
| Q4 | 断点集合 | **保持 480/768/1024**，不新增不下调；断崖由中档密度化解决，spec 契约零改动 |

## Requirements（定稿）

- R1 栅格与卡片尺寸（仅 `public/css/cards-detail.css`）：
  - base（=中档 769–1023）：`minmax(280px→180px, 1fr)`，gap `30→20`；`.vn-card-content` padding `20→16`
  - ≥1024（大档）：`minmax(300px→210px, 1fr)`，gap 显式 `24`
  - ≤768 / ≤480：栅格维持 `160/14`、`140/12` 不变（手机档现状可接受）
- R2 图片：`.vn-card-image` 固定 `height: 400px` 改为 `aspect-ratio: 7 / 10`；删除 768 档 `height: 280px`、480 档 `height: 220px` 覆写。
- R3 断点集合保持 `480/768/1024`，无 700px 残留，无 base.css 改动。
- R4 视觉不破坏：深色模式、详情弹窗、Tier 卡片区、NSFW 遮罩、光扫 hover 均不回归；不改卡片结构/配色/圆角语言。
- R5 已接受的权衡：卡宽变小后 `vn-card-title`（nowrap ellipsis）截断提前；移动端图高随 7:10 略变（768 视口 280→231、390 视口 220→247）。
